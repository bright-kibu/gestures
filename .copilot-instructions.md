# Copilot Instructions for Gestures Project

## Project Overview

This is a **C++ hand gesture recognition library** designed for embedded AI processors, specifically targeting **Hailo AI accelerators** and **Raspberry Pi 5 platforms**. The project combines computer vision, machine learning, and real-time processing to detect and classify hand gestures from camera feeds.

### Key Capabilities
- **Hand landmark detection** using MediaPipe-based models
- **Real-time gesture recognition** with custom trained neural networks
- **Live camera processing** with libcamera integration for Raspberry Pi 5
- **Hailo AI accelerator support** for optimized inference
- **Static library distribution** for easy integration into other projects

## Architecture & Core Components

### Main Classes and Modules

1. **`robot::Base`** (`Base.hpp/cpp`) - Abstract base class providing common functionality:
   - Debug utilities and profiling
   - OpenCV type aliases and utilities
   - Configuration management

2. **`robot::HailoInference`** (`Detector.hpp/cpp`) - Core AI inference engine:
   - Hailo device management and model loading
   - VStream abstraction for input/output handling
   - Thread-safe inference operations
   - Model lifecycle management

3. **`robot::Detector`** (`Detector.hpp/cpp`) - Palm/hand detection:
   - Hand detection using MediaPipe-style models
   - Bounding box and keypoint detection
   - Input preprocessing and output postprocessing

4. **`robot::Landmark`** (`Landmark.hpp/cpp`) - Hand landmark extraction:
   - 21-point hand landmark detection
   - 3D coordinate extraction (x, y, z)
   - Normalization and coordinate transformation

5. **`robot::Gesture`** (`Gesture.hpp/cpp`) - Gesture classification:
   - Feature extraction from landmarks (coordinates, distances, angles)
   - Neural network inference for gesture prediction
   - Extended finger detection and visualization
   - Supports classes: `fist`, `open_hand`, `point`

6. **`robot::DetectLiveCamera`** (`DetectLiveCamera.hpp/cpp`) - Real-time camera processing:
   - libcamera integration for Raspberry Pi 5 CSI cameras
   - Threaded processing pipeline
   - OpenCV visualization and display
   - Real-time gesture recognition overlay

### Data Pipeline

```
Camera Feed → Hand Detection → Landmark Extraction → Feature Engineering → Gesture Classification → Visualization
```

1. **Input**: Live camera stream (1536x864 default resolution)
2. **Detection**: Palm/hand bounding boxes using Hailo-optimized models
3. **Landmarks**: 21 3D hand keypoints extraction
4. **Features**: 
   - Raw coordinates (63 features: 21 points × 3 coords)
   - Pairwise distances (210 features: upper triangle of 21×21 matrix)
   - Finger angles (5 features: one per finger)
5. **Classification**: Neural network inference → gesture probabilities
6. **Output**: Gesture label + extended finger status + visualizations

## Build System & Dependencies

### Core Dependencies
- **C++17/C++20** compiler (g++)
- **OpenCV 4.x** - Computer vision operations
- **Hailo SDK** - AI accelerator support (`libhailort`)
- **libcamera** - Raspberry Pi camera interface

### Build Targets

```bash
# Build static library only
make lib                    # → libgestures.a

# Build main application
make main                   # → main executable

# Build everything
make all                    # Default target

# Clean artifacts
make clean

# Install system-wide
make install               # Copies to /usr/local/lib and /usr/local/include
```

### Makefile Features
- **Automatic dependency detection** (OpenCV via pkg-config)
- **Cross-platform support** (macOS Homebrew, Linux)
- **Custom path support**: `make OPENCV_PATH=/custom/path`
- **Debug/Release modes** with optimized flags
- **Dual C++ standard support** (C++20 for core, C++17 for camera)

### Model Management

Models are stored in `models/` directory:
- **`gesture_model.hef`** - Hailo-compiled gesture classification model
- **`gesture_model.tflite`** - TensorFlow Lite version
- **`label_encoder.joblib`** - Scikit-learn label encoder for gesture classes
- **`.har` files** - Hailo Archive formats for different optimization levels

Download gesture model:
```bash
wget https://github.com/bright-kibu/gestures/releases/download/0.0.1/gesture_model.hef
mkdir -p models && mv gesture_model.hef models/
```

## Development Guidelines

### Code Style & Standards
- **Namespace**: All classes under `robot::` namespace
- **Memory management**: Smart pointers (`std::shared_ptr`, `std::unique_ptr`)
- **Error handling**: Exceptions with descriptive messages
- **Thread safety**: Mutexes and condition variables for concurrent access
- **Resource management**: RAII principles throughout

### Key Design Patterns
- **Factory pattern**: Model loading and inference engine creation
- **Observer pattern**: Camera frame processing with callbacks
- **Template specialization**: Generic base classes with type-specific implementations

### Working with Models

1. **Model Loading**:
   ```cpp
   auto inference_engine = std::make_shared<robot::HailoInference>();
   robot::Gesture gesture("gesture_model", inference_engine);
   gesture.load_model("models/gesture_model.hef");
   ```

2. **Inference Pipeline**:
   ```cpp
   std::vector<cv::Point3f> landmarks = /* from landmark detection */;
   std::string predicted_gesture = gesture.predict(landmarks);
   auto extended_fingers = gesture.get_extended_fingers();
   ```

3. **Feature Engineering**: The system automatically extracts:
   - Normalized landmark coordinates
   - Euclidean distances between all landmark pairs
   - Joint angles for each finger
   - Extended finger binary flags

### Camera Integration

The `DetectLiveCamera` class provides a complete pipeline:
- **Initialization**: Automatic camera discovery and configuration
- **Processing thread**: Separate thread for AI inference
- **Display thread**: Real-time visualization with OpenCV
- **Cleanup**: Proper resource deallocation

### Testing & Validation

The project includes Python scripts for model development:
- **`gesture_data_extractor.py`** - Extract landmarks from image datasets
- **`gesture_model_builder.py`** - Train TensorFlow models
- **`generate_optimization_dataset.py`** - Create Hailo optimization datasets

When working on this project:

1. **Understanding the codebase**: Start with `main.cpp` → `DetectLiveCamera` → individual processing classes
2. **Making changes**: Focus on single responsibility - each class handles one aspect of the pipeline
3. **Testing**: Use the main application for end-to-end testing
4. **Model updates**: Re-train using Python scripts, convert to Hailo format, update model files
5. **Performance**: Profile using built-in debug flags and Hailo SDK tools
6. **Integration**: Build static library for use in other projects

## Troubleshooting Common Issues

- **Camera not found**: Check libcamera installation and permissions
- **Model loading failures**: Verify `.hef` file placement in `models/` directory
- **Hailo SDK errors**: Ensure proper SDK installation and device permissions
- **OpenCV linking**: Use `make config-check` to verify dependencies
- **Threading issues**: All camera and inference operations are designed to be thread-safe
